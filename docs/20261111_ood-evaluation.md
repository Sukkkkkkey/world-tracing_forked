## 数据选择

OmniObject3D 采用独立专业扫描，提供纹理网格与完整几何。原始论文介绍约 6,000 个物体和 190 类。本次实际访问的官方目录包含 216 个类别压缩包，使用所获取目录的完整快照与逐文件 SHA-256 固定版本。[项目说明](https://omniobject3d.github.io/) · [官方入口](https://github.com/omniobject3d/OmniObject3D)

HouseCat6D 可作为后续独立来源。官方网格包实测为 1,125,969,512 字节，已验证公开访问与包目录。它提供扫描网格及真实图像、深度、相机和物体姿态。该候选本轮仅完成获取条件核查。[数据说明](https://sites.google.com/view/housecat6d/dataset)

GSO、Toys4k、3D-FUTURE 出现在 WT 训练来源中。ABO 与 HSSD 出现在 TRELLIS.2 训练来源中。这些数据无法满足本轮要求的独立来源条件。Objaverse-XL 与 TexVerse 的在线资产还存在跨数据集转载可能。

## 评测条件

沿用 GSO v0.5 的单位、相机和指标定义。GT 按 AABB 对角线归一化，渲染 1024² RGBA，保留精确 504² 裁剪相机。输入方位由资产 ID 固定。源 OBJ 按 Y-up 处理，对应官方 Blender 默认 OBJ 导入约定，并通过样本渲染核查。[现有协议](evaluation_protocol_v0.5.md) · [官方渲染程序](https://github.com/omniobject3d/OmniObject3D/blob/main/tools/render_blender.py)

WT 使用已安装 r75b 物体 checkpoint 和六层点云，TRELLIS.2 使用现有 1024_cascade defaults-v1。两者均使用 seed 42，输入资产与视图相同，各自预处理及导出参数与 GSO 已有实验一致。WT 背景为灰色且无 alpha 腐蚀，TRELLIS.2 保留黑色背景和 2 像素腐蚀。完整参数保存于 configs/ood_inference.json。

完整几何、输入可见几何、输入深度、30 视角、覆盖率和法线沿用现有评测入口。TRELLIS.2 decoded 与 GLB 分别报告。配准为 GT 辅助的正 Sim(3)，24 个主轴初始化，10,000 配准点与 100,000 评价点。

正式集报告逐资产配对差值、95% bootstrap 区间、胜负数及类别分组结果。类别内样本相关性另用类别级重抽样检查。GSO 的正式比较基线为 R2 100 资产，P0 10 资产用于校准，二者分别列示。

GSO 与该 OOD 集的类别组成、扫描特征和难度均有变化。误差增长及排序变化可用于评价这批独立数据上的泛化，对训练拟合原因的归因仍需要资产交集证据或受控训练实验。论文 Table 1 的可见深度采用逐样本 scale–shift 对齐，公开深度表中没有 TRELLIS.2 行。当前主表为完整 Sim(3) 后的共同 surfel 重渲染深度。GSO 已保存的 input SSI 深度 MAE 为 WT 0.026336D（63/100 有效）、TRELLIS.2 decoded 0.016476D（85/100 有效），两项有效资产集合不同，配对比较需取交集。与论文数值的直接比较还涉及测试资产、单位与候选预算差异。[论文 Table 1](https://arxiv.org/html/2606.13652v1#S4)
