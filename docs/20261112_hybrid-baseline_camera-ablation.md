## 目标与解释范围

检验 WT 的有效内参与输入相机之间的差异，对完整形状、输入可见几何及相对深度结果的影响。分别比较 A、B 两组中每个方法在同资产两种输入相机条件下的变化，并考察 Hybrid 对 WT parent 几何的保持情况。

公开代码将 512² 下 fx=fy=500、cx=cy=256 标注为训练默认参考。按该矩阵计算水平 FoV 为 54.224893°。论文同时说明训练时随机化内参，训练内参的完整分布与检查点对应关系尚缺公开配置。本实验采用这组有代码依据的训练参考内参。[官方代码](https://github.com/haoz19/world-tracing/blob/main/wt/data.py) · [论文 §3.4、附录 C](https://arxiv.org/html/2606.13652v1#S3.SS4)

| 网格 | fx=fy | cx=cy |
| --- | ---: | ---: |
| 512² 参考 | 500 | 256 |
| 1024² 原图 | 1000 | 512 |
| 504² WT 实际输入目标 | 492.1875 | 252 |

当前检查点为 XYZ 输出模式，wt/inference.py 的扩散条件包含 RGB 和有效 mask，K 不参与采样；K 仅在 depth 模式反投影时使用。本消融改变输入图像的投影条件，不向网络注入真实 K。输出 XYZ 拟合出的 K 是几何诊断量，不能等同于网络显式接收的参数。

模型实际接收网格上的相机作为匹配对象。自动前景裁剪改变 K，若原图焦距为 f、裁剪边长为 l，则有效焦距为 504f/l。固定距离下仅改变原图焦距，l 也随物体投影变化，裁剪会抵消相当部分的焦距变化。

## 两组相机干预

### A 组，匹配最终内参与构图

| 条件 | 输入与相机 |
| --- | --- |
| A0 既有相机 | 复用冻结输入及真实 K_crop、T，原始渲染 FoV 40° |
| A1 训练参考相机 | 1024² 使用训练参考 K，保持资产观察方向与 roll，依据 GT 投影边界确定相机距离及横向构图，使最长前景边约占 2/3、前景中心接近画布中心，沿用自动裁剪 |

A1 的距离与构图由源几何确定，全部模型使用同一份 RGBA。最终匹配对象为 WT 504² 网格上的实际 K_crop，验收容差为焦距相对偏差≤0.2%、主点偏差≤1px。保存逐资产实际值、求解过程、占幅和距离。离散边界导致无法满足容差时，在推理前记录并修正渲染求解。

A 组估计参考内参与构图匹配的联合影响，距离变化引起的透视、表面可见性变化同时量化。

### B 组，固定外参与裁剪的内参对照

| 条件 | 输入与相机 |
| --- | --- |
| B0 原相机内参 | 使用 A0 的外参、原始 K 及由 A0 输入预先确定的裁剪/缩放 |
| B1 训练参考内参 | 外参和裁剪/缩放与 B0 完全相同，将原图 K 设置为 C_WT^(-1) K_target，使 WT 最终输入 K 为目标矩阵 |

C_WT 是 A0 的原图到 WT 504² 网格的二维仿射矩阵。每个模型内部的裁剪、缩放、前景定位或图像条件预处理都以 B0 确定的空间变换冻结，并在 B1 复用。背景合成、mask 腐蚀沿用各方法配置，记录适配前后的完整变换与图像摘要。B0/B1 使用相同的适配入口，保证干预后下游处理能够保持固定裁剪。

B 组保留相机距离、位置、旋转、画布和 GT 世界几何，焦距与主点作为内参整体切换。由此引起的物体占幅、输入像素密度与视锥覆盖变化纳入结果。渲染后若出现裁切或退化可见范围，按原预算记录，并附完整入镜资产的敏感性汇总。

B0、B1 均重新推理。B0 与 A0 的输入条件张量、几何输出和指标用于实现控制检查，逐项记录空间变换与数值差异。所有相机与空间变换在模型推理前根据 GT 和输入图冻结。

## 配对与评测

所有条件沿用 v0.5 指标，使用当前整图图像指标实现。固定源资产、纹理、归一化、朝向、光照、双面规则、采样 seed、GT 世界坐标评价点及 30-view 相机。输入相机干预产生新的 RGBA、GT 深度、可见标签和缓存签名，各条件均使用对应 GT。按 dataset、asset、method、config、stage、seed 配对。

| 类别 | 报告内容 |
| --- | --- |
| 完整几何 | 独立完整形状 Sim(3) 后的 CD-L1/L2、双向距离、Precision/Recall/F@0.01/0.05 |
| 可见几何 | 复用完整 Sim(3)，分别报告各条件输入可见区域，以及两条件都可见的同一组 GT 评价点上的配对结果 |

| WT L0＋SSI | 原像素 Z 与对应条件 GT 的有效交集，逐资产拟合 a、b，沿用正尺度、满秩、正深度与95%覆盖约束 |
| Input view / 30-view | 整图深度与法线 RMSE、PSNR、LPIPS，Silhouette IoU，深度/法线覆盖率、法线角误差及有效数量 |

### 2026-11-19 正式队列：四配置完整分析（GSO 50、OOD 50）

每个数据集取相同的 50 个资产，seed 42，评测协议 v0.5。A0、A1、B1 分别推理，B0 引用 A0 的同一输出与指标。共 1,200 份推理输出、2,100 个唯一评测阶段。WT 主表取原始点云，TRELLIS.2、default Hybrid、shared-WT Hybrid 主表取 decoded mesh。Pixal3D 的证据见 11 月 18 日五方法快照。

#### 可确认的结论与解释

**WT 与 TRELLIS.2 的几何排名随输入条件翻转。** 在 A0 和 A1，TRELLIS.2 的完整 CD-L1 在两个数据集都低于 WT。B1 下 WT 优于其余三个配置，六组资产配对的 95% 区间均支持该方向。TRELLIS.2 的 B1−B0 误差增幅绝对值约为 WT 改善幅度的 2.0 倍（GSO）和 5.1 倍（OOD）。OOD 上两个 Hybrid 的 B1 均值都低于 TRELLIS.2，但配对区间均跨零。

**WT 的输出具有可测量的投影偏置。** 用 WT 的 L0 XYZ 反拟合焦距，A0 的拟合焦距与真值之比为 GSO 0.686、OOD 0.634。B1 两者均接近 1，用真实内参重投影的误差从 51.36、60.80 px 降至 1.42、1.41 px。A1 也大幅缩小了投影错配，两个数据集的完整 CD 相对 A0 却都没有明确改善。XYZ 模式以 RGB 和 mask 为条件；这些观测支持对输入投影和构图的联合敏感性，无法单独估计焦距的因果贡献。

**覆盖同一片表面后，几何差异仍然存在。** 从 B0 到 B1，WT 的共同可见 CD 在两数据集都下降，TRELLIS.2 都上升。因而视角间可见表面集合的改变不足以解释方向翻转。两个 Hybrid 在 GSO 的完整和共同可见几何均改善，OOD 的四个对应区间均跨零。

**两种 Hybrid 的主要缺口在表面精度。** B1 下，default Hybrid 在 GSO、OOD 的 Recall@0.01 分别约 0.68、0.61，Precision 约 0.34、0.24；两种 Hybrid 的 decoded 表面积中位数均超过 GT 的三倍。组合起来看，模型覆盖了较多 GT 表面，同时生成了较多远离 GT 的表面点。面积与距离支持这一解释，无法据此确定冗余表面产生在哪一步。共享 WT 父输出后，两数据集 B1 的完整 CD 差值区间都跨零。

**输入图像与多视角回答不同的问题。** A1→B1 时，八个数据集×配置组合的输入深度和法线整图 LPIPS 均值都下降。WT 的 30 视角深度 LPIPS 却在两个数据集上升，TRELLIS.2 在 B1 的多视角深度 LPIPS 仍为四配置最低。输入物体缩小会改变背景比例，跨条件的深度图还使用各自 GT 的编码范围。输入整图的改善不能单独证明三维形状或新视角外观改善。

#### 可确认的结论与解释

**相机变化会改变方法排序，但不能归结为“匹配训练内参便全面改善”。** A0/B0 下，两数据集完整 CD 均值均为 TRELLIS.2 最好、Pixal3D 次之、WT 再次、两个 Hybrid 最差。B1 下 WT 的完整 CD 低于其余四配置，八组 WT 对照的未校正配对 95% 区间均不跨零；GSO 中 Pixal3D 均值排第二，OOD 中两个 Hybrid、Pixal3D、TRELLIS.2 的顺序仅是均值排序，彼此差值区间跨零。不能据此写成所有几何、深度和图像指标均由 WT 占优，也不能将 Hybrid 对 TRELLIS.2 的微小均值优势写成稳定优势。

**WT 的投影内参偏置有直接证据，三维几何收益则取决于输入条件。** L0 XYZ 反拟合的 fx/GT fx 在 A0 为 GSO 0.697、OOD 0.661；B1 接近 1，GT K 下重投影误差由 49.38/53.43 px 降至 1.42/1.48 px。相比之下，用 XYZ 自身拟合 K 的误差各条件仅约 0.2–0.4 px，说明点云内部投影关系可以自洽，而与真实输入 K 存在系统错配。A1 同样意图匹配最终 K，但完整/共同可见 CD 相对 A0 的变化在两数据集均未形成明确改善；B1 相对 B0 的共同可见 CD 在两数据集都改善，完整 CD 只在 GSO 有区间支持。因此证据支持 WT 对内参及其伴随的构图、距离/透视关系敏感，尚不能将三维误差全部归因于焦距，或断定较小占幅本身就是唯一偏好。

**Pixal3D 补充了不同于 TRELLIS.2 的响应。** GSO 中 A1−A0 的完整 CD 增加 0.005289D；改用同运行期 B0 作控制仍增加 0.005176D [0.002020,0.008797]，因此不能由 A0/B0 的小幅重跑差异解释。GSO B1−B0 仅增加 0.000948D，区间跨零；其 B1−A1 均值下降也未获得区间支持。OOD 中 B1−B0 的完整和共同可见 CD 分别增加 0.010274D、0.010727D，两者区间均大于零；B1−A1 的物理深度 MAE、输入 IoU、多视角深度 LPIPS 同时退化。Pixal3D 对这组输入干预的敏感性具有数据集差异，不能照搬 TRELLIS.2 在 GSO 的退化结论，更不能仅据最终排名认定二者具有相同焦距先验。

**TRELLIS.2 在 B1 的退化更一致。** B1−B0 的完整 CD 在 GSO/OOD 分别增加约 95.9%/152.9%，完整与共同可见差值区间均为正。B1 冻结原裁剪框而缩小前景，使其偏离默认紧裁剪输入，物体可用像素和透视同时变化；这是已有设计支持的候选解释，尚未通过“固定最终占幅和细节，仅改 K”的独立干预分离贡献。该结果说明模型及固定预处理组合对这组输入敏感，不等同于确定模型隐含了某个具体焦距。

**Hybrid 主要问题仍是表面精度，未由相机匹配或共享 WT 父输出消除。** B1 的 default Hybrid 在 GSO/OOD 上 Precision@0.01 约 0.342/0.231，Recall 约 0.699/0.610；面积/GT 均值约 7.79/8.08，中位数仍为 3.10/3.85。shared-WT 的对应表现相近。高覆盖、高召回不等于准确，低精度及偏大面积支持存在较多偏离 GT 的表面；面积本身不能区分体积外扩、内层/重复面和局部高频表面。两个 Hybrid 在各条件完整 CD 的直接差值区间均跨零，当前没有共享 WT 父输出带来稳定改善的证据。B1 的 F@0.01 仍为 WT 最高，而 OOD 中 Hybrid 的 F-score 低于 TRELLIS.2/Pixal3D，与 CD 均值排序不同，进一步说明不能只用一个指标宣告整体胜出。

**相对深度与三维表面需要分别判断。** 各自口径下 WT 的 RMSE 都较低。固定共同像素且双方都做 SSI 后，GSO 的 RMSE 均值略偏向 WT，OOD 略偏向 TRELLIS.2，配对差的 95% 区间均跨零。OOD 的 MAE 支持 TRELLIS.2，低 0.00396D [0.00091, 0.00755]。放宽 95% 共同覆盖门槛后，GSO 的 50 个可拟合资产在重合像素上支持 WT（RMSE 低 0.00731D），OOD 的 48 个资产仍无法判定。三维可见 CD-L1 在两组均为 WT 均值略低，但差值区间也都跨零。

**内参匹配有利于 WT 的投影一致性，不能保证其可见表面优于 TRELLIS.2。** 0→B1 后，WT 的真实相机重投影误差在 GSO/OOD 从 51.36/60.80 px 降至 1.42/1.41 px。固定 WT B1 和源图，GSO 中三方共同覆盖达标的 21 个资产上，TRELLIS.2 从 B1 恢复紧裁剪至 B1.5 后，双方均做 SSI 的 RMSE 从 0.02098D 降至 0.01520D，WT 为 0.01396D。OOD 仅 6 个资产通过三方覆盖筛选。B1 的相对优势同时受两种方法的输入设置影响，B1 与 B1.5 的批量执行方式也有差异。

**综合结论。** WT 能较好地保留输入图像中可见表面的相对深度起伏。固定预测点云后，完整形状配准在可见面和遮挡面之间作出折中，使可见面留下更大的对齐残差。这项结果支持对配准的解释，生成阶段对可见面与遮挡面的估计能力仍需单独检验。在各自适配的输入条件下，WT B1 与 TRELLIS.2 B1.5 的可见表面估计总体相近。同像素相对深度 RMSE 的均值排序随数据集改变，三维可见 CD-L1 的配对差在两组均跨零。当前单 seed 结果未显示 WT 具有跨数据集的一致优势，统计等效性尚未检验。
